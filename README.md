# Tournée d'Annabelle la criminelle

Appli web installable (PWA) pour organiser une tournée infirmière : passages du jour, vue semaine, patients et soins.

Les données des patients ne sont **jamais** dans ce dépôt ni sur Internet : elles restent uniquement dans le téléphone qui utilise l'appli (avec export/import de sauvegarde).

Adresse de l'appli : https://corsepgm.github.io/Tourn-e/
